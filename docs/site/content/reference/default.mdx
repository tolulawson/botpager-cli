# botpager default

## Synopsis

```text
botpager default <ref>
```

## Arguments and options

| Argument / option | Meaning |
| --- | --- |
| `ref` | Exact destination ID or name. |

## Behavior

Saves the resolved device ID as the profile default. Does not send a message or rename a destination.

## Example

```sh
botpager default "Work phone"
```
