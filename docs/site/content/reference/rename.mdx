# botpager rename

## Synopsis

```text
botpager rename <old> <new>
```

## Arguments and options

| Argument / option | Meaning |
| --- | --- |
| `old` | Exact reference of the paired phone. |
| `new` | New phone destination name. |

## Behavior

Updates the server’s phone destination name and this profile’s local alias. Does not rename the sending computer.

## Example

```sh
botpager rename "Work phone" "Office phone"
```
