# botpager unlink

## Synopsis

```text
botpager unlink <ref>
```

## Arguments and options

| Argument / option | Meaning |
| --- | --- |
| `ref` | Exact destination ID or name. |

## Behavior

Revokes the pairing and removes it locally. A server response of 401 or 404 is treated as an already removed pairing. Removing the saved default selects the first remaining saved destination, if any.

## Example

```sh
botpager unlink "Work phone"
```
