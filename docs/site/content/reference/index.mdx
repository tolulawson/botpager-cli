# Command reference

The command is `botpager`. Global flags are `--help` / `-h` and `--version`. Command options use a separate value, such as `--title "Ready"`.

| Command | Purpose |
| --- | --- |
| [pair](/reference/pair/) | Connect this computer to a phone. |
| [send](/reference/send/) | Save a message for a paired destination. |
| [devices](/reference/devices/) | List locally saved destinations. |
| [default](/reference/default/) | Set the profile’s default destination. |
| [rename](/reference/rename/) | Rename a phone destination. |
| [unlink](/reference/unlink/) | Revoke a pairing and remove it from the profile. |
| [status](/reference/status/) | Report API health and local profile status. |
| [upgrade](/reference/upgrade/) | Check or install the latest stable CLI release. |

[Configuration](/reference/configuration/), [installation](/reference/installation/), and [output and errors](/reference/output/) describe the shared contract.
