# BotPager CLI

Send an update from your terminal to your phone. Pair once, then use BotPager from a shell script, CI job, or coding agent.

[Quick start](/quick-start/): install the CLI, pair your phone, and send your first update.

For a guided walkthrough with expected results at each step, follow the [first-message tutorial](/tutorials/first-message/).

## Get something done

- [Install the CLI](/how-to/install/) on macOS, Linux, or Windows.
- [Choose a phone](/how-to/choose-phone/) when you have multiple destinations.
- [Notify from a script or agent](/how-to/automate/) without losing a job’s exit status.
- [Upgrade or remove BotPager](/how-to/upgrade/).
- [Recover from an error](/how-to/troubleshoot/).

## Look something up

[Command reference](/reference/) covers every command. [Configuration](/reference/configuration/) lists environment variables and local files. [Output and errors](/reference/output/) describes JSON, exit codes, and delivery results.

Read [About pairing and credentials](/explanation/pairing/) and [About message delivery](/explanation/delivery/).
